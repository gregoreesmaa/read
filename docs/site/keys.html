Selection

Drag to select across headings, paragraphs, lists, tables, and code. Double-click locks in a word; triple-click selects the line. Code blocks show a hover Copy button; links open in the browser.

Scrolling

Code blocks and tables scroll horizontally — hover-activated, independent per block, clamped so the content's right edge meets the container. Trackpad swipes glide 1:1; wheel notches glide via retarget.
