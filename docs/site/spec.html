Supported Markdown

Strictly CommonMark plus GFM tables and task lists. Full HTML rendering is intentionally unsupported — only a blessed inline subset (br, kbd, sub, sup, mark, del) renders; everything else stays visible as muted mono.

Blocks

  • ATX headings #–###### (optional closing #), Setext === / ---
  • Fenced code (```, ~~~) + indented code, with syntax highlighting
  • Blockquotes incl. nested >>; GitHub alerts (> [!NOTE]) tint the bar
  • Unordered (* - +), ordered (1. 1)), task (- [ ]) lists
  • GFM tables with alignment and dividers
  • Diagrams: mermaid, d2, Graphviz, PlantUML (cached render, code fallback)
  • Math via ZaTeX: ```math fences, whole-line $$…$$, inline $…$
  • YAML frontmatter renders nothing

Inlines

  • **bold**, *italic*, ***both***, ~~strike~~, `code`
  • Links [text](url), autolinks, bare https:// URLs, images
  • Backslash escapes (\*, \_, …)
Try it: open showcase.md in Read — every construct above renders on one page. Math setup: engine guide.
