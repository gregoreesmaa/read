# Size-diet decisions (issues #115–#311)

Batch evaluation of the 197 binary-diet micro-optimization proposals, one verdict
per issue. Method per issue: read the proposal, check the tree (`build.zig`,
`src/`, `scripts/`), measure where a measurement exists (`zig build
-Doptimize=ReleaseFast` + `./scripts/size_gate.sh`, `file`, `otool -l`,
`size -m`, `strings`, `nm`), and either confirm prior art, reject on
platform/architecture/benchmark grounds, or run the isolated experiment.
Only one proposal (#117, ship-only `single_threaded`, −64B) won implementation
(PR #312, merged); #168 rode with merged PR #111.

Shared baseline (main, 2026-09): ship binary 177848B (`size_gate.sh` PASS,
budget now 200 KiB per owner decision), Mach-O 64-bit arm64, `__TEXT` 130376B,
`__LINKEDIT` one page (16384B, minimum), 0 `__chkstk`/`__stack_chk` refs,
0 panic strings, 0 error-name strings in the binary.

Verdict classes: **done** = already implemented / already absent / tested with
no gain / rejected against an immutable constraint (benchmarks, spec,
correctness); **not-planned** = inapplicable to this target (ELF/Windows/
Linux-only/packer/network/rewrite proposals).
